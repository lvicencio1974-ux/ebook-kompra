## Ondas de Calma

App web de relajación con pulsos binaurales y respiración guiada (`ondas-de-calma/index.html`).
Ábrela en cualquier navegador moderno y usa audífonos. Incluye sesiones para casa, trabajo,
caminando y una sesión personalizada, con referencias a los estudios en que se basa cada una.

### Instalarla en el celular

La app es una PWA: se instala desde el navegador y funciona sin internet.

1. Une esta rama a `main`.
2. En GitHub: **Settings → Pages → Source: GitHub Actions**. El workflow `Publicar Ondas de Calma`
   publicará la carpeta `ondas-de-calma/` en `https://<usuario>.github.io/ebook-kompra/`.
3. Abre esa dirección en el celular:
   - **Android (Chrome):** toca **Instalar** en el aviso de la app, o menú ⋮ → *Instalar app*.
   - **iPhone (Safari):** botón Compartir → *Agregar a inicio*.
