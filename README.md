## Ondas de Calma

App web de relajación con pulsos binaurales y respiración guiada (`ondas-de-calma/index.html`).
Ábrela en cualquier navegador moderno y usa audífonos. Incluye sesiones para casa, trabajo,
caminando y una sesión personalizada, con referencias a los estudios en que se basa cada una.
